## גיליון תשובות (להעתיק לקובץ `quiz-answers.md`)

בשאלות אמריקאיות כותבים רק את האות. בשאלות הפתוחות, משפט או שניים.

```
# בוחן שיעורים 1-2: <שם מלא>

שאלה 1: מה המשפט הכי מדויק על DevOps?
תשובה: ג. דרך עבודה: אחריות משותפת על הקוד מהכתיבה ועד שהוא רץ אצל המשתמשים.

שאלה 2: "סימנו את גרסה 1.2 כמוכנה לעלות לשרת". לאיזה שלב בלולאה זה שייך?
תשובה: ב. Release.

שאלה 3: באפליקציה מונוליטית יש באג שמפיל את דף התשלום. מה קורה?
תשובה: ב. כל האפליקציה עלולה ליפול, כי זה תהליך אחד.

שאלה 4: איך שני מיקרו-סרוויסים מדברים זה עם זה?
תשובה: או בצורה סינכרונית, שבה שירות אחד שולח בקשה וממתין לתשובה, או בצורה אסינכרונית, שבה הוא שולח הודעה לתור וממשיך לעבוד בלי לחכות.

שאלה 5: ב-ShopList, למי פונה הדפדפן?
תשובה: ג. רק ל-frontend.

שאלה 6: למה stats לא צריך את הסיסמה של מסד הנתונים?
תשובה: כי הוא פונה ל-backend ולא למסד הנתונים בעצמו.

שאלה 7: תני חיסרון אחד של מיקרו-סרוויסים.
תשובה: במקום לנהל דבר אחד, יש המון חלקים קטנים לטפל בהם. וכשמשהו נשבר, קשה להבין באיזה מהם הבעיה.

חלק ב — Docker (שיעור 2)

שאלה 8: מה ההבדל בין image ל-container?
תשובה: Image זה כמו מתכון: כתוב בו בדיוק מה צריך ואיך מכינים, אבל הוא לא משתנה. Container זה העוגה שאופים לפי המתכון, וממתכון אחד אפשר לאפות כמה עוגות שרוצים.

שאלה 9: מחקתי container עם docker rm. מה קרה ל-image שלו?
תשובה: ב. נשאר.

שאלה 10: container לעומת מכונה וירטואלית. מה נכון?
תשובה: ב. containers משתפים את ה-kernel של המחשב, ולכן הם קלים ועולים בשניות.

שאלה 11: בפקודה docker run -p 8080:80 nginx:1.30-alpine, מה המספר 8080?
תשובה: הפורט במחשב המארח.

שאלה 12: מה עושה EXPOSE 5000 ב-Dockerfile?
תשובה: ב. מתעד שהאפליקציה מאזינה בפורט 5000, ולא פותח כלום.

שאלה 13: למה מעתיקים את requirements.txt ומתקינים את התלויות לפני שמעתיקים את app.py?
תשובה: כדי שאם ישתנו שורות ההעתקה והקוד האחרות, לא יצטרכו לעשות חזרה את ההתקנות הכבדות.

שאלה 14: למה השרת בתוך container מאזין ל-0.0.0.0 ולא ל-localhost?
תשובה: כי localhost בתוך container זה רק ה-container עצמו, ואז אי אפשר להגיע לשרת מבחוץ. 0.0.0.0 פותח אותו לפניות מכל מקום.

שאלה 15: למה הקוד של ה-backend קורא את הסיסמה ממשתנה סביבה ולא כותב אותה בקוד?
תשובה: מטעמי אבטחה.

שאלה 16: הרצתן את stats לבד. ‎/health מחזיר 200, ו-‎/stats מחזיר 502. למה?
תשובה: ‎/health רק בודק שהשירות חי. ‎/stats צריך נתונים משירות אחר שלא רץ, ולכן הוא נכשל.

שאלה 17: מה ההבדל בין docker stop ל-docker rm?
תשובה: stop עוצר את ה-container ואפשר להפעיל אותו שוב, rm מוחק אותו לגמרי.

שאלה 18: ב-docker run hello-world לא כתבנו גרסה. מה Docker הוריד, ולמה זה לא מתאים לסרוויס אמיתי?
תשובה: הוא הוריד את latest. זה לא מתאים כי latest מתחלף כל הזמן, ופתאום יכולה לרדת גרסה אחרת שתשבור את המערכת.
